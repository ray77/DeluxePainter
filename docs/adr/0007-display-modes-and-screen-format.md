# ADR-7: Display modes, Screen Format requester and UI scaling

- Status: accepted (Phase 2, 2026-11-10)
- Context: DeluxePaint IV AGA lets the user choose the display mode in the "Choose Display Mode" requester (at start-up and via Picture ▸ Screen Format). Loaded pictures need their own mode (e.g. 320×200 NTSC LoRes), and hardware limits are document rules.
- Decision:
  - `dpx_core::mode`: `DisplayMode` = video (PAL/NTSC) × resolution (Lo 320 / Hi 640 / SuperHi 1280) × interlace; standard sizes, CAMG ModeID, BMHD aspect, integer pixel shape and the size of a LoRes UI pixel. `Target` = chipset + mode, stored in the `Document`; default AGA, PAL LoRes. Colour limits: OCS LoRes 32, HiRes 16, no SuperHiRes; AGA 256 everywhere. HAM/EHB are not modelled yet; overscan and custom screen sizes followed in ADR-11.
  - `Command::SetFormat { mode, colors, width, height, retain }`: validated against the chipset (`UNSUPPORTED_MODE`, `PALETTE_RANGE_INVALID`); with `retain` the picture is kept top-left and colours it uses must stay; without it the page is cleared. New palette entries get a grey ramp until DeluxePaint's AGA default palette is known. Undo restores the whole document (page, palette, target).
  - The requester opens **only from the menu** (owner decision 2026-11-10; the original also shows it at start-up). Like the AGA original it is drawn on its own PAL HiRes 640×256 screen with Workbench-style colours (grey, black, white, blue). Controls: mode list with scroll bar, selected-mode field, display information, Screen Size (Standard only), Page Size (Screen / Keep Same), Palette Size slider (powers of two), Retain Picture, credits, Use / Cancel; keys ↑/↓, Enter, Esc, U, C, R. A refused format keeps it open with the reason in the information panel.
  - Screens follow the document mode: the window shows each screen pixel with its pixel shape (HiRes 1×2, SuperHiRes 1×4, laced halves, at an integer scale). The interface keeps its LoRes geometry and artwork; in finer modes every UI pixel covers 2 or 4 screen pixels, so it looks the same in every mode. DeluxePaint uses separate HiRes artwork; that is a recorded deviation until such artwork exists.
  - `--open` picks the mode from CAMG, otherwise from the size (≥640 wide = HiRes, ≥1280 = SuperHiRes, >283 lines = laced, ≤200 lines per field = NTSC).
- Consequences: ILBM export can write the document's CAMG and aspect (with Picture ▸ Save). SuperHiRes non-laced needs a window at least 1024 physical pixels tall.
